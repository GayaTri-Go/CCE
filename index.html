Cybersecurity for beginners: how to not get hacked (no cap) 🛡️

5 min read • for absolute beginners

How many times today did you unlock your phone, log into something, or pay via UPI? 📱💸 Each one is worth protecting. Cybersecurity is keeping your devices, accounts and data away from people who shouldn't have them. You don't need a dark hoodie to get it, just the right mental model. 🧠✨

🔺 The CIA triad (not the spy one 😭)

  • 🤐 Confidentiality: only the right people see the data. Your DMs stay yours.
  • ✅ Integrity: nobody secretly changes the data. Your bank transfer amount stays the same.
  • ⚡ Availability: systems work when you need them. The exam portal doesn't crash from an attack.

Next time you read about a breach, ask which of the three got broken. Instant brain upgrade. 📈

🚨 Threats you'll actually meet

  • 🎣 Phishing: a fake message from your "bank", college or delivery app. It always creates panic ("blocked in 2 hours!!"). Panic is the trap.
  • 🔑 Weak and reused passwords: one site leaks yours and attackers try it everywhere else (credential stuffing).
  • 🦠 Malware: hides in cracked apps, random APKs and attachments. Ransomware locks your files until you pay.
  • 🎭 Social engineering: hacking the human, not the computer. A fake "support agent" calls you.
  • 🕸️ Unpatched software: old apps have known bugs, and attackers love them.

💅 Your glow-up checklist

  1. 🗝️ Use a password manager. Make every password unique and long.
  2. 📲 Turn on MFA for email, socials and banking. Authenticator apps beat SMS.
  3. 🔄 Update phone, laptop, browser and apps. Switch on auto-updates.
  4. 🧐 Pause before you click, and never share your OTP. Ever. 🚫
  5. 🏪 Install apps from official stores only. No cracked software, bestie.
  6. ☁️ Back up important files in two places.
  7. 📶 Skip banking on public Wi-Fi, or use a VPN you trust.
  • Unique password on my email 📧
  • MFA on email and main socials 🔐
  • Auto-updates on 🔄
  • One backup of important files 💾
  • I can spot a phishing message 🎣

Next up: getting comfy in the terminal, because most security tools live there. 🐧

📚 Reference: CISA, Secure Our World (cisa.gov), covering phishing, passwords, MFA and updates.

Linux commands every security beginner should know 🐧

7 min read • practise on a VM

Tools like Nmap, Wireshark and Metasploit are happiest in a Linux terminal. 🖤 Learn these commands and security tutorials stop looking like magic. 🪄

⚠️ Rule #1: practise only on your own machine or a VM. Never scan or test systems you don't own or lack permission to test.

📍 1. Know where you are

pwd      # where am I?
ls -la       # list files, incl. hidden
cd /var/log  # go into a folder
cd ..        # go up one level

Hidden files (starting with .) are where configs, and sometimes suspicious stuff, hide. 👀

🗂️ 2. Create, copy, move, delete

mkdir notes
touch file.txt
cp file.txt backup.txt
mv backup.txt old.txt
rm old.txt     # no recycle bin!

Careful with rm -rf. No undo button. 😭

👓 3. Read files fast

cat file.txt
less bigfile.log      # q to quit
head -n 20 file.log
tail -n 20 file.log
tail -f auth.log      # follow live 🔴

tail -f is gold: watching logs in real time is a core SOC skill. 🕵️‍♀️

🔍 4. Search like a detective

grep "failed" /var/log/auth.log
grep -i "error" app.log
grep -r "password" ~/projects
find / -name "*.conf" 2>/dev/null

🔒 5. Permissions

ls -l script.sh
chmod 700 script.sh     # owner only
chmod +x script.sh      # make executable
chown user:group file

In -rwxr-xr-- the chunks are owner | group | everyone else. Setting everything to 777 is a classic misconfiguration. 🙅‍♀️

👤 6. Users and privileges

whoami
id
sudo cmd    # run ONE command as admin

Use sudo only when needed. Living as root is the opposite of least privilege. 👑❌

⚙️ 7. Processes and system info

ps aux
top
kill 1234
uname -a
df -h

Weird process eating your CPU? ps aux is where the investigation starts. 🔎

🌐 8. Networking basics

ip a
ping -c 4 google.com
ss -tuln                      # listening ports
curl -I https://example.com   # HTTP headers

ss -tuln shows what's listening on your machine, a quick way to spot services you didn't mean to expose. 👁️

🔗 9. Pipes = combo moves

cat auth.log | grep "Failed" | wc -l

The | feeds one command's output into the next. This counts failed login lines. ⚡

🆘 10. Get help

man grep
grep --help

Nobody memorises everything. Reading man pages is the real superpower. 📖

🎮 Practice challenge

  1. 📁 Make a folder, create 3 files and list them with ls -l.
  2. 🔐 Change one file's permissions so only you can read it.
  3. 🔍 Use grep to count a word in a log file.
  4. 🌐 Run ss -tuln and work out what each port is.

You don't need 200 commands. Master these ten groups, practise in a safe lab, and every command you understand makes you stronger. 💻🔐

📚 Reference: GNU Project, GNU Coreutils Manual (gnu.org), covering file and text utilities and permissions.
